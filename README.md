# Vidhana & Co. Tax Tracker

An internal app for tracking tax advice, client receipts and IRD payments. See `PLAN.md` for the specification and `CLAUDE.md` for the stack, commands and conventions.

## Local setup
1. `npm install`
2. Copy `.env.example` to `.env.local` and fill in the Supabase URL and publishable key.
3. `npm run dev`, then open http://localhost:3000.

Staff accounts are created by invitation from the Supabase dashboard. The app has no sign-up.
